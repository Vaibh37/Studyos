Get started with StudyOS

StudyOS brings planning, focus, notes and progress into one student productivity workspace. Start with a simple routine and build it around the way you study.

Get started
The workspace

How it works

01

Choose how to start

Open StudyOS to see the available sign-in and guest options. Choose the option that fits how you want to use the workspace.

02

Set up your first subject

Create a subject for a course or topic you are studying. Add a task and a note so the workspace reflects your current priorities.

03

Start studying

Choose a focus duration and record a session. Return to your progress page to review your study activity.
